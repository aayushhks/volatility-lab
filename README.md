# Volatility Lab

An original, AI-assisted research starter that converts option quotes into an auditable implied-volatility surface. Inspired by the **project category** featured in Coding Jesus's quant researcher video; no code from Mateusz Jastrzębski's application was copied or available for review.

## What it does

- Fetches option chains for a user-selected ticker through `yfinance`, imports CSV quotes, or runs entirely offline with deterministic synthetic European option prices.
- Validates bid/ask quotes, uses the midpoint, solves Black–Scholes–Merton implied volatility, and records a reason for every rejection.
- Displays an interactive 3D surface, expiry smile slices, near-spot term structure, and a quote-level audit.
- Exports the audit and a self-contained JSON snapshot that can be replayed without fetching new data.
- Includes a dependency-free pricing engine with numerical tests, plus a polished browser demo.

## Run the Python application

Python 3.12 recommended. From this directory:

```sh
python -m venv .venv
source .venv/bin/activate
# Windows PowerShell: .venv\Scripts\Activate.ps1
pip install -r requirements.txt
streamlit run app.py
```

Start with **Synthetic demo**. Choose **Yahoo Finance**, enter a ticker such as SPY, and click **Fetch option chains**. A failed request is shown explicitly; it is never silently replaced with synthetic data. Yahoo access can fail or be rate-limited. No provider subscription is bundled. Review the provider's data usage terms before redistribution or commercial use.

CSV columns:

| Column | Meaning |
|---|---|
| strike | Positive strike price |
| days | Positive fractional days remaining **at the observation time** |
| bid / ask | Positive quotes in the same units as spot |
| kind | `call` or `put` |
| open_interest | Optional; defaults to zero |

An example is in `examples/quotes.csv`. Its underlying spot is 100, continuously compounded rate 4%, and continuous dividend yield 1%. These are synthetic data, not SPY history.

## Reproduce results

```sh
python -m unittest discover -s tests -v
python -m volatility_lab.replay examples/snapshot.json --output audit.csv
python scripts/build_demo.py
```

The standard-library test suite checks a known call/put pricing example, put–call parity, IV recovery across strikes and volatilities, vega against finite differences, invalid prices, invalid inputs, quote filters, synthetic fixture recovery, volatility monotonicity, and the zero-volatility boundary. CI runs those tests on Python 3.12.

The browser demo is static and **does not fetch live prices**. It loads precomputed synthetic fixtures generated by the Python engine. Run `python -m http.server 8000 --directory dist` and open http://localhost:8000 to view it locally. Its canvas surface supports rotation/zoom without WebGL; the Python app uses Plotly. Browser rate/yield assumptions are fixed at 4%/1%; the Python app exposes both as inputs. The scenario changes the synthetic quote set; controls select a side, horizon and spread threshold. Export reflects the current filters.


## Method

For spot S, strike K, maturity T, continuous rate r and dividend yield q:

- d1 = [ln(S/K) + (r − q + σ²/2)T] / (σ√T)
- d2 = d1 − σ√T
- Call = S exp(−qT) N(d1) − K exp(−rT) N(d2)
- Put = K exp(−rT) N(−d2) − S exp(−qT) N(−d1)

The solver uses bracketed bisection on [0.000001, 5] with a 1e−8 absolute price tolerance and 160 iterations. Prices outside the strict European no-arbitrage bounds, or on those boundaries, are rejected. After inversion, quotes with vega below 0.01 price units per unit volatility are rejected as unstable. This threshold is a configurable-code heuristic, not a universal financial standard. Accepted quotes are repriced and their absolute residual is exported.

The synthetic examples generate prices from a known smile, then recover the hidden IV from bid/ask midpoints. Known IV is retained in the fixtures for test comparison; it is not used by the inversion routine.

The displayed surface joins adjacent grid values. **There is no fitted or arbitrage-free interpolation model.** Missing points stay missing. The near-spot term curve uses each expiry's nearest available strike and is not a constant-delta curve.

## Architecture

- `volatility_lab/core.py`: pricing, vega, IV solver and quote-quality audit; standard library only.
- `volatility_lab/data.py`: deterministic scenarios and optional Yahoo adapter.
- `volatility_lab/replay.py`: offline reproduction from exported snapshots.
- `app.py`: Streamlit controls, charts and exports.
- `tests/test_core.py`: numerical and data-quality checks.
- `dist/`: browser demo loading Plotly.js 2.35.2 from its official CDN for 2D charts (internet required).
- `scripts/build_demo.py`: reproducible fixture/archive generation.


## Held-out quote experiment

The research panel compares global constant IV, expiry-specific constant IV, and linear smile interpolation on identical held-out interior strikes. It reports price MAE/RMSE, IV error, and bid/ask agreement, and exports the complete source snapshot, assumptions, and predictions. It also works offline when Yahoo is unavailable.

Run `python scripts/evaluate_surface.py` to reproduce the committed results in `examples/synthetic-holdout-results.json`: three synthetic scenarios, each evaluated with seeds 7, 42, and 2026. Run `python -m unittest discover -s tests -v` for numerical, cache, memory-bound, and leakage checks.

These fixtures are generated using the same pricing model used for evaluation. They demonstrate interpolation correctness, not market accuracy or alpha. The experiment holds out strikes within a snapshot; it does not forecast future prices, test extrapolation, or enforce arbitrage constraints. Market conclusions require real timestamped snapshots.
